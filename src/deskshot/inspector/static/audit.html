how an item works

  1. missed — boxes are hidden on purpose. Click anything visible that has no box, then Enter. You cannot see what is not drawn on a screen already covered in boxes, so this pass comes first.
  2. screen — a few one-key judgements about the whole annotation.
  3. elements — the sampled elements, one at a time. a is correct and moves on; any other flag accumulates and Enter commits, so an element can be both misclassified and mislocalized.

Every answer is saved the moment you press the key. There is no save button and nothing is written to the corpus.
